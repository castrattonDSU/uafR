# Standardize curated plant-compound intake

Standardize curated plant-compound intake

## Usage

``` r
standardizePlantCompoundIntake(x)
```

## Arguments

- x:

  Data frame containing at least \`species\` and \`compound_name\`.
  Recommended columns include \`source_database\`, \`citation_or_url\`,
  and \`evidence_tier\`.

## Value

A normalized \`PlantCompoundOccurrences\` data frame.

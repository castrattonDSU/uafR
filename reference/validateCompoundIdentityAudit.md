# Validate a compound identity audit table

Validate a compound identity audit table

## Usage

``` r
validateCompoundIdentityAudit(x)
```

## Arguments

- x:

  Identity audit table or object accepted by
  \`standardizeCompoundIdentityAudit()\`.

## Value

List with \`Summary\`, \`TableQuality\`, \`Issues\`, and \`Audit\`.

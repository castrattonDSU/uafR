# Sample Chemical Library

A library of chemicals in wide format, intended to highlight important
features of the package in the vignette

## Usage

``` r
library_data
```

## Format

A data frame with 7 rows and 5 columns:

- Type.A:

  The first set of chemicals

- Type.B:

  The second set of chemicals

- Type.C:

  The third set of chemicals

- Type.D:

  The fourth set of chemicals

- Type.E:

  The fifth set of chemicals

# Supplemental data set for Tables 1 and 2 in publication

A data frame containing raw output from Agilent's Unknowns Analysis

## Usage

``` r
published_data
```

## Format

A data frame with 2432 rows and 7 columns:

- Component.RT:

  Retention time of captured component

- Base.Peak.MZ:

  Mass to charge ratio (m/z) of captured component

- Component.Area:

  Area quantified for captured component

- Compound.Name:

  Tentative compound identity for captured component

- Match.Factor:

  Library match factor for captured component (i.e., accuracy of
  identification)

- Sample.Name:

  Name of sample from which component was captured

- File.Name:

  Name of file from which component was captured

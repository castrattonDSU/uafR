# Supplemental data set for Figure 1 in publication

Contains summary data that was used for linear model figures/analyses of
standards data.

## Usage

``` r
standards_model_data
```

## Format

A data frame with 15 rows and 7 columns:

- uafR.RT:

  Retention Time identified by uafR for referenced chemical

- uafR.Mass:

  Exact Mass found by uafR for referenced chemical

- PubChem.Mass:

  Mass shown on PubChem web interface for referenced chemical

- Chemical:

  Name of chemical

- Sample:

  Sample from which the chemical was identified

- ng.Injected:

  Amount of standard chemical injected into sample

- uafR.Peak.Area:

  Total component area identified by uafR for referenced chemical

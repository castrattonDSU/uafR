# Sample Data Set for External Standards

A mock data set to show the correct format for the \`ES_calibration\`
input when using \`standardifyIt()\` with an External standard \#'

## Usage

``` r
ExternalStandard_data
```

## Format

\## \`ExternalStandard_data\` A data frame with 28 rows and 4 columns:

- Quantity:

  Measured Amount of Analyte in Sample

- Component.Area:

  Area/Quantity of Analyte

- Component.RT:

  Retention Time of Analyte

- Replicate:

  Experimental Replicate

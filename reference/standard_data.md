# Standard GC/MS Output

A subset of data from a study running 3 samples containing known
quantities of standard chemicals – (1) ethyl hexanoate, (2) methyl
salicylate, (3) octanal, and (4) undecane.

## Usage

``` r
standard_data
```

## Format

\## \`standard_data\` A data frame with 63 rows and 8 columns:

- Component.RT:

  Retention Time

- Base.Peak.MZ:

  Captured M/Z Value

- Base.Peak.Area:

  Area/Quantity of Chemical

- Compound.Name:

  Name of Tentative Chemical

- Match.Factor:

  Accuracy of Tentative Match

- Sample.Name:

  Sample name

- File.Name:

  Redundant - use sample name

# Training Data

This directory is reserved for training datasets that should ship with the
curriculum but are not part of the R package itself.

Recommended contents:

- Small GC-MS example tables that can be shared publicly.
- Metadata dictionaries for student projects.
- Non-sensitive sample sheets.
- Frozen result files for teaching when internet access is unavailable.
- Template CSV files for chemical intake, grouping dictionaries, and evidence
  tables.

Do not store private participant information, unpublished collaborator data, or
API tokens in this directory.
